# 提示词模板

## 通用模板

```
请参考参考图1的剪切和排版手法，用参考图2/3/4的{风景}实景照片，制作一张竖版3:5的复古旅行手账式撕纸拼贴海报：
1) 剪切手法（严格学参考图1）：所有照片都是手撕毛边+白色纸芯纤维边；三种切法混用——整块不规则撕块、半轮廓撕法（撕线大致顺{轮廓}走但留松弛余量）、可以有一小块精确剪影；碎片下有极轻投影。
2) 排版（严格学参考图1）：非网格、非对称，碎片沿一条隐含的S形路径从右上铺到左下；大小对比悬殊；照片块之间基本不互叠，靠奶白纸张缝隙隔开；缝隙宽窄不一，窄处让蓝色路线穿过，像缝合线。
3) 手绘底图（重点）：纸面预印层/手绘底图必须是{底图主题}——{地貌元素列表}；整体像一张手绘的{类型}地图，铅笔/淡褐墨线、低饱和淡彩（灰绿、灰褐），散布在整张纸面作为底图；留白占画面三到四成。
4) 照片内容：{照片安排}。
5) 装饰：点缀少量{呼应色}的小色块，小面积克制。
6) 文字：左下角一行小号打字机英文 {主文案}，下面一行更小的 PUZHEHEI，字距拉开、灰褐色，拼写必须正确。
7) 禁止：人物（含远景人影）、水印、杂乱文字、大标题、霓虹色、3D效果、整齐矩形照片、拍立得白框。
```

## 荷塘示例

```
1) 剪切手法：手撕毛边+白色纸芯纤维边；整块不规则撕块、半轮廓撕法（顺荷花/荷叶轮廓）、可有一小块精确剪影；碎片下极轻投影。
2) 排版：S形路径从右上到左下；大小对比悬殊；照片块不互叠、纸缝隔开；窄缝让蓝线穿过。
3) 手绘底图：普者黑喀斯特地貌风格——圆润锥形峰林、峰丘等高线、溶洞与地下河示意、湖泊水网线稿；铅笔/淡褐墨线、低饱和淡彩（灰绿、灰褐）；留白三到四成。
4) 照片内容：荷塘作为最大主块偏上，荷花特写作为中块，可再裁一块荷塘局部做小碎片。
5) 装饰：少量粉色荷花花瓣点缀空白（散落、稀疏、自然）。
6) 文字：Lotus / Pond / Silence + PUZHEHEI。
7) 禁止：人物、水印、杂乱文字、大标题、霓虹色、3D、整齐矩形照片、拍立得白框；禁止黑色/墨色荷花（必须是粉色）。
```

## 峰林示例

```
1) 剪切手法：同通用（顺山脊/峰形轮廓走）。
2) 排版：同通用。
3) 手绘底图：喀斯特峰林+峰丘等高线+溶洞/地下河示意+湿地水网/湖塘线稿。
4) 照片内容：俯瞰喀斯特峰林湿地（夕阳金光）作最大主块偏上；峰林村庄远景（已裁掉人物）作中块；可再裁一块湿地水面局部做小碎片。
5) 装饰：少量暖金色（呼应夕阳）。
6) 文字：Sun / Water / Ridge + PUZHEHEI。
7) 禁止：同通用。
```

## 船游示例

```
1) 剪切手法：同通用（顺船身/山岸轮廓走）。
2) 排版：同通用。
3) 手绘底图：水岸喀斯特地貌地图——沿水岸锥形峰林、峰丘等高线、湖泊水网与水路线稿、水面波纹、芦苇/溶洞示意。
4) 照片内容：粉色小船游湖照片作最大主块偏上居中（小船完整：船头、船身、荷叶彩绘）；俯瞰喀斯特峰林湿地作中块；可再裁一块山岸水面局部做小碎片。
5) 装饰：少量粉色（呼应小船）。
6) 文字：Boat / Mist / Karst + PUZHEHEI。
7) 禁止：同通用（含远景小船人影）。
```

## 提示词注意事项

- 需要 3-4 张输入图时，参考图放第 1 张，风景照随后（qwen-image 系列最多支持 3 张输入图）。
- 要求"必须且只有 N 块碎片、位置如何"时，用强约束句（"绝对不要合并成一块，也不要只出现一块"）。
- AI 文字渲染不可靠：出图后无论是否正确，都可用 `overlay_text.py` 覆盖为精确文字。
